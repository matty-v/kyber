# Kyber v1.5.0

Release candidate notes. Changes since v1.4.1; publication pending approval.

## New features

- **Slack conversations:** connect an agent to Slack from Comms using Socket
  Mode, a bot token, and explicit user/channel allowlists. Claude Code and Codex
  can receive text and send threaded replies without exposing Slack tokens to
  the runtime. Restart the agent pod after configuration changes. Attachments,
  reactions, and interactive buttons are not part of this initial Slack bridge.
- **Private agent avatars:** upload, replace, or remove a PNG, JPEG, or WebP
  avatar up to 1 MiB from General settings. Images use authenticated API access.
  The installation currently needs durable tasks enabled and task object
  storage configured for this feature.
- **Simpler console navigation:** agent details group observation, automation,
  and configuration; Settings groups fleet defaults, observability, health,
  and API access. Desktop uses a local rail and mobile a full-screen menu.
  Existing Metrics and Logs links remain usable.
- **Versioned harness integration contract:** Claude Code and Codex expose
  runtime descriptors, auth modes, and observed feature availability. Shared
  services use runtime-owned auth, session, transcript, repair, and receipt
  contracts. Missing or stale capability evidence prevents unsupported task
  and job controls from being advertised as ready.

## Fixes and cleanup

- Include the Slack sidecar's release image tag in the packaged Helm chart,
  matching the image built by release CI.
- Generate the release change range from the previous stable Kyber tag instead
  of accidentally selecting an independently versioned PWA package tag.
- Correct documentation for Slack, profiles, disk/runtime recovery, portable
  versus node-local storage, authenticated model discovery, durable tasks/A2A,
  PWA publication, and operator-controlled upgrades.
- Remove an unused skills-report helper and an unreachable release-script
  compatibility fallback.

## Upgrade notes

Use the released Helm chart and apply its CRDs before upgrading; Kyber's
self-upgrade Job performs that CRD step. This release includes Agent schema and
both runtime integration changes from the harness/Slack/profile features.
Release CI builds nine images, including Slack, for amd64 and arm64.

Publishing this release does not install it on any cluster. Use the installation's
update mechanism and verify its reported version afterward. Existing agents
retain their configured authentication modes; the compatibility API fields and
routes remain available. Runtime feature availability depends on observed
integration health, and the conformance guide retains explicit evidence gaps.

PWA views are independently versioned at 0.40.0. External hosts must consume the
published package version; the embedded console ships with the control plane.
