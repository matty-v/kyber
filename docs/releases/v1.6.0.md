# Kyber v1.6.0

Changes since v1.5.0. Prepared for publication on 2026-09-10.

## New features

- **Hermes agent harness:** create and operate Hermes agents alongside Claude
  Code and Codex. The preview supports API-key authentication through
  OpenRouter, fresh-session restart, native session resume, model and context
  reporting, authenticated model discovery, token usage, skills, and Telegram,
  Discord, and Slack channels. The console exposes Hermes authentication,
  observed provider/model/context data, and stable harness versions.
- **Full Slack conversations:** Slack agents can now edit messages, react with
  emoji, transfer scoped files in both directions, and present interactive
  Block Kit buttons in addition to text and threaded replies. A `mentionOnly`
  option limits shared channels to direct mentions, replies to the bot, and
  direct messages. User and channel allowlists continue to be enforced by the
  sidecar, and runtime tools never receive Slack credentials.

## Fixes

- Publish the Slack sidecar in main-branch canary charts so a newly installed
  canary actually contains the Slack build represented by that chart.
- Send Slack external-upload reservation fields using Slack's expected form
  encoding, restoring outbound file uploads. Upload failures now retain
  bounded field-level validation details in the tool error and sanitized
  diagnostics in sidecar logs.

## Upgrade notes

Use the released Helm chart and apply its CRDs before upgrading; Kyber's
self-upgrade Job performs that CRD step. Release CI builds the complete image
set for amd64 and arm64, including the Hermes runtime and Slack sidecar.

Hermes remains a preview and requires an installation-level Hermes image tag
plus an OpenRouter API-key credential. It does not advertise durable tasks,
scheduled-job turn hooks, subscription login, context compaction, or runtime
repair.

For Slack rich features, review the Slack app configuration before rollout.
The bot needs the history scopes for subscribed conversation types plus
`chat:write`, `reactions:read`, `reactions:write`, `files:read`, and
`files:write`. Socket Mode must be enabled, event subscriptions and interactivity
must reach the app-level connection, and the bot must be a member of each
allowlisted channel. Reinstall the Slack app after changing scopes. Existing
Slack configurations default to accepting all allowlisted messages unless
`mentionOnly` is enabled.

Publishing this release does not install it on any cluster. Apply it through
the installation's update mechanism and verify the reported version and agent
rollouts afterward.

PWA views are independently versioned at 0.43.0. External hosts must consume
the published package version; the embedded console ships with the control
plane.
